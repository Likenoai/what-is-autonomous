# 自主性研究方向与当前研究边界

> [!summary] 本文用途
> 记录 2026-11-17 关于人类自主性形成、心理需求作用以及 Agent 理由系统的讨论，作为长期研究地图。**它不改变当前研究主线：目标自我一致性（Goal Self-Concordance）。**

## 1. 当前研究边界

当前主线研究的是**目标自我一致性（Goal Self-Concordance）**，而不是所有广义的目标一致性（Goal Congruence / Goal Alignment）。

核心问题：

> 一个人追求的目标，在多大程度上符合其自身的兴趣、价值观和认同？这种一致性如何影响持续努力、目标达成、心理需求满足及幸福感？

当前窗口继续围绕目标自我一致性展开。人类自主性的进化起源、完整自主性理论和 Agent 自主性架构属于相关但更宽的后续研究方向，不应混入当前主线。

## 2. 新增研究方向 A：人类自主性的形成

### A1. 进化起源

研究问题：人类在进化过程中，如何逐渐形成灵活调节行为、依据理由行动并反思自身目标的能力？

候选子问题：

- 从固定刺激—反应到灵活行为选择：预测、学习、抑制控制与规划如何发展？
- 社会生活如何影响自主调节：合作、相互依赖、社会学习、规范与声誉机制发挥什么作用？
- 语言、抽象思维和反事实推理如何支持理由表达与检验？
- 元认知和自我反思如何使主体能够评价自己的欲望、目标和判断？

研究约束：不能把这些能力预先假定为专为“自主性”进化而来。它们可能分别服务于生存、学习、合作和环境适应，后来才组合成更复杂的能力。需要区分进化功能假说与现代主体对这些能力的使用。

### A2. 自主性的构成与边界

当前工作定义（暂定，尚非公认的完整定义）：

> 自主性，是主体形成和理解行动理由，依据理由评价和选择行动，并能根据新事实、经验及反思，修正原有判断、目标或行动方式的能力。

需要继续区分：

- 行为控制与自主性；
- 目标执行与目标形成；
- 动机强度与动机质量；
- 按理由行动与事后为行动编造理由；
- 主体认可目标与目标在伦理上值得追求。

关键研究问题：一个主体如何从“有欲望、追求目标”发展到“能够审查自己为什么追求这个目标”？

## 3. 新增研究方向 B：心理需求在自主性与目标形成中的作用

以自我决定理论（Self-Determination Theory, SDT）为重要理论入口，重点研究三种基本心理需求：

- **自主性（Autonomy）**：行动是否具有自愿性，主体是否认可行动的原因。
- **胜任感（Competence）**：主体是否感到自己能够有效行动并影响结果。
- **关系感（Relatedness）**：主体是否体验到与他人的联结、关怀和归属。

尚待研究的问题：

1. 心理需求在动机产生之初发挥什么作用？
2. 需求满足与需求受挫如何影响目标选择、目标价值和投入？
3. 外部要求如何经过内摄、认同和整合，逐渐成为主体认可的目标？
4. 心理需求是否参与目标自我一致性的形成，而不只是影响目标追求过程中的体验？
5. 需求满足、目标达成和主观幸福感之间如何区分，三者是否存在不同路径？

重要边界：

- 心理需求不是目标本身，也不能直接等同于动机。
- 需求满足不等于目标达成；需求受挫也不只是需求满足的简单反面。
- 受到家庭、文化或社会影响，不自动意味着目标不自主；需要考察主体能否理解、认可和反思这些影响。
- 自主性动机不自动证明目标正确、可行或符合伦理要求。

## 4. 新增研究方向 C：Agent 的理由驱动系统

工程研究问题：

> 能否让 Agent 不仅生成行动解释，而且让理由真实参与目标评价、决策控制和反馈修正？

候选功能模块：

1. **理由识别**：从任务、环境、记忆和约束中识别事实、目标、偏好、价值、义务与风险。
2. **理由评价**：核查证据、来源、可信度、重要性和适用条件。
3. **理由冲突处理**：处理目标冲突、事实冲突、偏好冲突和约束冲突。
4. **目标形成与分解**：在给定任务边界内形成候选目标和子目标。
5. **理由驱动行动**：让理由实际影响计划选择、工具调用和停止条件。
6. **反馈与修正**：根据新事实和行动结果更新事实判断、策略、目标或评价标准。
7. **边界与治理**：区分可自适应的目标和规则，以及必须保持稳定或需要人类批准修改的约束。

关键验证问题：

- 理由是否真实影响行动，而不只是出现在自然语言解释中？
- 改变一个关键理由，是否会在其他条件不变时引起可预测的决策变化？
- 当证据推翻原有判断时，Agent 能否更新相应判断，而不是机械坚持？
- 当目标失去依据或与更高优先级约束冲突时，Agent 能否停止或重新规划？

可探索的验证方法：反事实测试、理由移除实验、干预实验、决策轨迹审计和反馈更新测试。

重要边界：Agent 的功能性理由系统不能直接等同于人类的主观体验、心理需求或人类自主性。当前目标是研究可检验的功能机制，不预设 Agent 具有人的感受。

## 5. 三条研究线之间的关系

| 研究线 | 核心问题 | 当前定位 |
| --- | --- | --- |
| 目标自我一致性 | 目标是否符合主体兴趣、价值和认同？这种一致性如何影响追求过程？ | **当前主线** |
| 人类自主性形成 | 人如何形成、评价和修正自身目标与理由？心理需求发挥什么作用？ | 长期基础研究 |
| Agent 理由驱动系统 | 如何让理由参与目标评价、行动和反馈修正？ | 并行工程探索 |

三条线可以相互启发，但不能简单等同：

- 目标自我一致性是研究目标与自我之间关系的一种具体理论构念，不等于完整自主性。
- 人类自主性涉及动机、认知、反思、社会关系和行动调节等更广泛机制。
- Agent 可以实现某些理由识别和自我修正功能，但这不足以证明其拥有与人类相同的心理需求或主观自主体验。

## 6. 与当前目标自我一致性研究的衔接

当前已经建立的理论脉络：

1. **目标自我一致性研究**：目标越符合个人兴趣和核心价值，越可能支持持续努力；目标达成后，也可能更充分地转化为心理需求满足。
2. **自我决定理论**：已讨论外部调节、内摄调节、认同调节、整合调节和内在动机，并区分自主性动机与受控动机。
3. **心理需求**：已区分自主性、胜任感、关系感的满足与受挫，并明确成功和需求满足不是同一结果。
4. **情境期望—价值理论（SEVT）**：已整理成功预期、内在价值、效用价值、成就价值和感知成本，用于解释目标选择与投入。详见 [[情境期望—价值理论]]。

当前主线尚待深入：

- 目标自我一致性在目标形成之前如何产生？
- 心理需求如何影响初始动机、目标选择和目标内化？
- 内摄、认同与整合调节如何形成和变化？它们与目标自我一致性之间是什么关系？
- 当目标进展、环境或个人价值发生变化时，主体如何重新评价目标？
- 如何区分坚持、调整、目标脱离和重新投入的不同机制？

## 7. 当前讨论的范围约定

- 当前讨论继续聚焦**目标自我一致性**及其前因、机制、结果和边界。
- 讨论心理需求时，优先考察它们如何参与目标形成、内化及目标一致性的变化。
- 暂不把讨论扩展为完整的人类进化史、自主性哲学或 Agent 自主性架构。
- 上述宽方向保留在本笔记中，待当前主线推进到合适位置后再独立展开。
