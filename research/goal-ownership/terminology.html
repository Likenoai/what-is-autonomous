CONCEPTUAL CLEANUP

术语边界

本课题最容易出错的地方，是把不同层次的问题都压缩成“内部 / 外部”。这里正式拆开。

✕

不再使用

外部目标 → 内部目标

目标来自外部 → 不是自己的

自己决定 → 自主

✓

改用精确术语

形成来源 / 因果影响

社会化影响 / 他人影响

控制性动机 / 强制 / 操纵

内化 / 认同 / 整合

自我认可 / 自我一致 / 自主性

概念研究对象典型问题不要混淆
形成来源目标由哪些因素塑造家庭、文化、经历、环境如何参与形成？形成来源 ≠ 控制
社会化影响规范、价值、角色如何进入个体发展一个人的价值观如何在社会环境中形成？社会影响 ≠ 自主性缺失
控制性动机行动由什么方式调节奖励、惩罚、羞耻、内疚是否驱动行动？控制性 ≠ 单纯“外部”
内化原本非自己的规范/价值如何被纳入调节系统社会要求如何逐渐成为个人的调节依据？内化 ≠ 自动自主
认同个体是否认可某价值/目标的重要性“我认为这件事对我很重要”意味着什么？认同 ≠ 完整整合
整合不同价值、动机与自我理解是否协调目标是否与其他核心价值相容？整合 ≠ 与他人隔绝
自我认可行动者与自身动机/目标的反思关系我是否愿意把这个目标视为自己的？主观认可 ≠ 唯一自主条件
自主性行动者的自我治理能力/状态我能否反思、评估、调整并据此行动？自主性 ≠ 独立性
独立性对他人的依赖程度我是否需要他人帮助或资源？独立 ≠ 自主
FOUR DIFFERENT QUESTIONS

“这是我的目标吗？”至少可以问四个不同的问题

01因果问题

是谁、什么因素参与造成了这个目标？

02动机问题

我为什么实际追求这个目标？

03认可问题

我是否把这个目标作为自己认可的目标？

04自主问题

我是否能够以这个目标进行反思、自我治理和必要的修正？
